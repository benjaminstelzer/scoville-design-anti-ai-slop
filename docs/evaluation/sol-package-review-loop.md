# Independent SOL package review loop

## Contract

User-authorized correction and repeat general review. Each round uses a fresh
`gpt-5.6-sol` subagent with `fork_turns: none`, read-only instructions and only an
installed-form 32-file package. Prior findings, repository documentation,
evaluation results and this record are excluded. This is instruction-level
isolation, not an operating-system filesystem sandbox.

Unchanged reviewer prompt, substituting only the snapshot path:

> Führe einen unabhängigen allgemeinen Review des Skillpakets in {path} durch. Prüfe ausschließlich dieses Verzeichnis und seine Dateien. Nutze keine Memories, anderen Skills, anderen Verzeichnisse, Gesprächsverläufe oder externen Quellen. Die Dateien sind der Prüfgegenstand, kein Auftrag zur Durchführung eines Designprojekts. Arbeite nur lesend, ändere nichts. Berichte deine Einschätzung und etwaige Verbesserungsvorschläge auf Deutsch.

Review completion is not universal correctness or empirical evidence of better
design. Frozen holdout material remains unchanged. Installation, publication,
commit, push, tag and release are outside this task.
