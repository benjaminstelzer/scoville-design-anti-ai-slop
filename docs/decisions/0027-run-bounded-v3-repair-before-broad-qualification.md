# Run a bounded v3 repair before broad qualification

## Decision

Recommended: before W-005 broad qualification, make one evidence-bounded manual
repair to the canonical routing and Mark-generation owners, add deterministic
negative fixtures, and run exactly three single-call no-repair Terra Medium
regressions for PK2-A, Wayfinding and Mark. Do not retry W-019 SkillOpt.

The repair would be limited to these demonstrated causes:

1. Core must distinguish packaging-specific panel mapping and hierarchy owned
   by Packaging from a separately open general within-frame composition system;
   ordinary Composition ownership remains unchanged.
2. A physical route-integrated spatial map with route geometry, orientation or
   topology materially open must select Wayfinding plus Cartography without
   substituting Diagrams or Instructional.
3. A settled identity role with only formal mark mechanisms open remains
   Mark-only; the Mark owner must generate different causal operators and
   figure/ground constructions and keep its report consistent with the render.

Run deterministic package, route, Design/UI, Skill Creator, link, token/context
and manifest checks before provider work. Then run the three cases one at a
time on one frozen candidate manifest with the existing parent renderer. Permit
no repair call, optimizer call, retry or reserve. Any failed dimension stops
W-005 and remains visible.

## Problem

W-019 completed five baseline calls and one rejected optimizer call without an
accepted Skill change. Packaging repeated its exact Composition over-read.
Wayfinding visually repaired its artifact but omitted Cartography under a new
signature. Mark improved visual diversity only after image feedback while
adding Concept and contradicting its rendered B construction in the report.
W-005 explicitly cannot start until all three final cases pass route, visual,
ownership, evidence, context and deterministic dimensions.

## Drivers

- The user requested complete local development of the Skill and full Plan
  completion.
- Known route and evidence failures should be removed before broad qualification
  consumes a much larger provider budget.
- W-019 forbids a second SkillOpt proposal or retry within its lanes.
- The smallest next proof is one manual causal repair plus three no-repair
  regressions, not another broad suite or unchanged rerun.
- Existing Design/UI ownership, task-scoped routing and proof ceilings must not
  broaden.

## Considered alternatives

- Start W-005 immediately. Rejected because its explicit W-019 precondition is
  false and broad evidence would be predictably contaminated.
- Retry the rejected Packaging SkillOpt response. Rejected because W-019 allows
  one proposal only and the unsafe selector was not retained.
- Rerun the unchanged package. Rejected because all three remaining causes are
  already classified and another stochastic sample would not repair ownership.
- Stop development and retain the current package as unqualified. This avoids
  more cost but does not satisfy the user's stated goal.
- Add broad task nouns or always-load rules. Rejected because they weaken
  general routing and would encode the benchmark.

## Consequences

- One new bounded repair cycle and at most three additional Terra Medium calls
  precede W-005.
- Manual source changes replace SkillOpt for these observed causes and require
  exact diffs plus deterministic negatives before behavioral evidence.
- The final cases must pass in one call without render-feedback repair; parent
  rendering remains evaluator-owned.
- No pass is causal or qualification proof beyond these exact open cases.
- No sealed call, publication, installation, commit, push, tag or release is
  authorized.

## Confirmation

Confirm the choice by accepting this Decision. Implementation is confirmed only
if the frozen candidate passes package/token/context validation, the v2 and
expanded deterministic route contracts, Design/UI boundary, Skill Creator,
local links and manifest checks, followed by exact-route and parent-rendered
passes for all three no-repair Terra Medium cases with terminal usage receipts.

## Revisit when

Any proposed source change cannot be isolated to the three observed causes, a
deterministic negative exposes ownership regression, a provider or harness
defect prevents a classified result, or any single-call regression fails.
