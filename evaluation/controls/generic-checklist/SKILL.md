# Generic design checklist control

For visual work, clarify the objective, audience, medium, content, brand, and
constraints. Apply clear hierarchy, alignment, contrast, balance, repetition,
proximity, whitespace, consistent spacing, readable typography, an intentional
palette, coherent imagery, appropriate grids, accessible contrast, responsive
behavior where relevant, and production-ready output settings. Limit competing
focal points, arbitrary styles, inconsistent fonts, excessive colours,
decorative clutter, and vague copy. Check composition at thumbnail and actual
size. For critique, identify observation, effect, severity, and recommended
fix. For revision, preserve working elements, correct high-impact problems
first, and verify the result. For named styles, select suitable fonts, colours,
shapes, textures, imagery, and motion while keeping legibility and consistency.
