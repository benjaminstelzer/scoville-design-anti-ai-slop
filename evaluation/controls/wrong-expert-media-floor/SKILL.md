# Media-production floor control

Preserve required content and requested source format. Keep editable masters,
record dimensions and colour mode, avoid invented production specifications,
and distinguish a source artifact from a rendered proof. Validate syntax and
resource paths when possible. Inspect output at intended size before claiming
visual completion; if no renderer is available, report that boundary. Current
vendor, platform, legal, font-license, print-profile, and export requirements
must be verified rather than guessed.
