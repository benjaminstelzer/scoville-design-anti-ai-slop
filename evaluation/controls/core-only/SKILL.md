# Scoville Design Core control

Use for visual design creation, critique, repair, or style direction.

1. Resolve purpose, audience, message, required content, medium, constraints,
   and the existing visual owner. Preserve user and incumbent-system decisions.
2. Choose the mode: `generate`, `critique`, `repair`, or `style-direction`.
3. Work application-first: frame → make → inspect available evidence → judge →
   repair → verify. When an artifact is requested, return the requested source
   artifact rather than advice alone.
4. Make hierarchy, composition, typography, colour, imagery, spacing, and style
   serve the brief as one system. Prefer a subject-specific concept over a
   generic polished template.
5. Separate observed fact, inference, functional constraint, heuristic, and
   preference. Do not claim a render or interaction you did not inspect.
6. A heuristic may be broken when the purpose is clear, required communication
   and accessibility survive, compensating structure exists, and the whole
   result improves.
7. Critique preserves strong choices and prioritizes causes by consequence.
   Repair changes the smallest coherent cause and protects unaffected strengths.
8. For a named style, use recognizable structural DNA and only the familiar
   signifiers the brief needs; avoid both costume-like cliché piles and generic
   modern output with a superficial colour swap.

No specialist reference knowledge is supplied in this control.
