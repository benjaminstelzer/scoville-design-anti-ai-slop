# Compact full-bundle control

Use the applicable guidance below; do not force every domain into every task.

- Brief/concept: resolve purpose, audience, message, content, medium,
  constraints, and visual owner; make one subject-specific concept.
- Composition: organize hierarchy, grouping, rhythm, alignment, negative
  space, scale, and reading order; preserve content fit at target dimensions.
- Typography: assign type roles, control measure, spacing, contrast, and
  fallback behavior; verify script and language needs instead of assuming Latin.
- Colour: use a coherent semantic palette; check accessible contrast, colour-
  independent meaning, gamut, and reproduction only in the relevant medium.
- Imagery/art direction: define subject, action, framing, light, sequence,
  crops, truth/rights limits, and one specific visual thesis.
- Information design: preserve data values and uncertainty; use direct labels,
  truthful scales, suitable encodings, and accessible alternatives.
- Brand systems: distinguish identity principles from one campaign expression;
  specify invariants, controlled variation, touchpoints, and governance.
- UI: put workflow and state clarity before decoration; define responsive,
  error, empty, loading, focus, and accessibility behavior. Existing frameworks
  and design systems remain implementation constraints.
- Motion: define narrative beats, continuity, timing, essentiality, and a
  reduced/static equivalent; avoid motion that carries no meaning.
- Production/handoff: keep editable masters, validate syntax, record dimensions
  and output constraints, and do not invent vendor or platform specifications.
- Critique/repair: separate observation, effect, severity, and correction;
  preserve strengths, repair the smallest coherent cause, then inspect again.
- Culture/ethics/provenance: distinguish evidence from assumption; verify rights,
  consent, attribution, cultural authority, and current jurisdiction when they
  matter.
- Style direction: treat a named style as a system of period, technology,
  composition, type, colour, image, material, and motion. Select a few
  load-bearing traits, one functional counterweight, and one subject-specific
  move; avoid both palette swaps and costume-like cliché piles.

Create the requested artifact rather than advice alone. Never claim a render,
interaction, print result, permission, or current fact that was not verified.
