# Exclude fixed specialist geometry and routine artifact writing

## Decision

Accepted automatically under the user's standing instruction to accept project
decisions: repair only the two public ADR-0047 over-read mechanisms in the Core
router and direct index.

Composition requires an open general within-frame spatial decision. When a
specialist owns the only open geometry or label relation and the general visual
system is fixed, select the specialist without Composition. Media Production
requires an open production-source/derivative, technical export, preflight,
format-semantics, provider-acceptance or handoff decision. Merely writing the
requested editable artifact or checking its syntax does not select Media
Production.

Add a model-free route fixture for a fixed relational-diagram template whose
only open work is source-defined connectors and labels. It expects Diagrams and
forbids Composition, Typography, Instructional and Media Production. Regenerate
the direct index, rebuild the executable package manifest and run all existing
package, route, module-index, Design/UI and Skill Creator gates before any
targeted provider verification.

## Problem

The source-cleared ADR-0047 case fixed every node coordinate, canvas, type,
colour, spacing and visual hierarchy. Only three source-defined relations were
open. The package nevertheless loaded Diagrams, Composition and Media Production
instead of Diagrams alone. The artifact and terminal report were otherwise
valid, so broad package or expert rewrites are not justified.

## Drivers

- Fix the reproduced cause rather than one private symptom.
- Preserve specialist geometry ownership and ordinary artifact creation.
- Keep genuine open layout and production decisions routed to their owners.
- Add a reusable negative-boundary fixture.
- Avoid another provider call until deterministic gates pass.

## Considered alternatives

- Remove Composition or Media Production generally. Rejected because both own
  valid open decisions.
- Change the public Gold. Rejected because the source-cleared brief explicitly
  fixes those concerns.
- Special-case SVG or the fixture token. Rejected as test-specific behavior.
- Treat every connector placement as Composition. Rejected because Diagrams owns
  relation geometry when the general canvas system is fixed.
- Treat every written file as Media Production. Rejected because that would load
  production for nearly every editable artifact task.

## Consequences

- The Core and Media Production route label become narrower.
- Genuine general composition or production decisions remain selectable.
- The package manifest changes and all earlier manifests remain historical.
- One targeted public post-fix verification may be needed; no sealed rerun is
  required.
- W-005 was already in progress, so its immutable Decisions list cannot add
  ADR-0048; mutable Evidence records the repair.
- Publication, installation, commit, push, tag and release remain unauthorized.

## Confirmation

Confirm the new negative fixture, unchanged positive Composition and Production
fixtures, generated-index consistency, token report, all validators, a new
manifest and at most one separately authorized source-cleared post-fix call with
no retry or sealed content.

## Revisit when

A task leaves both specialist relation geometry and general spatial hierarchy
open, production semantics become part of ordinary artifact creation, or another
public regression contradicts either exclusion.
