# Build and qualify Scoville Design Anti-AI-Slop

## Goal

Create a source-grounded, independently usable `scoville-design-anti-ai-slop`
Skill for designing and critiquing graphic, editorial, brand, web, and UI work.
Prioritize applied generation, design discrimination, rendered repair, and
professional style execution; treat theory and history as selectively loaded
tools rather than the main product output.
Require every routed expert to provide professional task depth rather than a
list of topic names: formal variables, failure diagnosis, generation,
critique, repair, exceptions, and proof must be operational and source-bounded.
Update `scoville-ui-anti-ai-slop` so Design owns design definition and judgment
when both Skills are active and applicable, while UI owns strict framework and
design-system implementation and retains its standalone Greenfield fallback.
Optimize both Skills with SkillOpt and qualify their design behavior, routing,
solo operation, and composition boundaries with controlled and rendered tests.
Before changing the successor package, reconcile the completed reference audit
into an exact implementation Plan and obtain fresh SOL and Fable 5.1 reviews
with no unresolved Blocker or High-priority defect.

## Non-goals

- Publish a GitHub release, push a remote branch, or install either Skill into
  Codex, Claude, or another host without separate explicit authorization.
- Replace artifact-format Skills, image generation, UI frameworks, design
  systems, or professional human approval.
- Turn design heuristics, aesthetic preferences, style trends, or numeric
  conventions into universal laws.
- Copy books or third-party Skills into the package without a verified license
  path, attribution, and an intentional repository licensing decision.
- Vendor third-party books, screenshots, comparison images, or evaluation
  datasets into either repository; restricted reference material remains in a
  separate local-only evaluation workspace if it is used at all.
- Claim general graphic-design competence from routing checks, source linting,
  one attractive artifact, or one model/host configuration.
- Repackage design-history or foundation knowledge that the frozen SOL baseline
  already applies reliably without a measurable Skill intervention.
- Treat broad topic coverage, one good critique, or a terse list of variables
  as proof that an expert reference is professionally complete.
- Optimize reference size before professional coverage, correctness, causal
  repair knowledge, exception handling, or proof requirements are complete.
- Measure or claim behavioral qualification for Fable 5.1 or Opus 5; Fable's
  one-time Plan review remains separate process evidence.
- Treat historical SOL XHigh development evidence as Terra High qualification
  or pool results across the two executors.
