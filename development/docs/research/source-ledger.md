as runtime dependencies. Its canonical source identifiers are the fifty-nine
`SRC-*` families defined in
[`references/source-index.md`](../../../scoville-design-anti-ai-slop/references/source-index.md). That file is

[`rule-source-map.md`](rule-source-map.md).

aliases. They preserve where an admitted source family was assembled from and
prevent the same work from acquiring several apparent authorities. An alias is
not an extra runtime source and does not broaden a source's scope or licence.
