This map binds local rule clusters to the admitted source families in
[`references/source-index.md`](../../../scoville-design-anti-ai-slop/references/source-index.md). It is audit
documentation, not runtime instruction. Routed expert references must contain
the complete, independently worded rules they apply. Normal design work neither
loads this map nor fetches the sources.

## Evidence relation

- `foundation` supplies professional vocabulary, questions, and methods.
- `convention` records convergent practice with contextual exceptions.
- `empirical` supports only the studied population, task, and outcome.
- `standard` is binding only in its stated medium, version, jurisdiction, or
  conformance scope.
- `worked example` demonstrates one functioning system, not a universal recipe.
- `current authority` must be rechecked when the actual decision depends on its
  present version.

Several sources can converge on one local rule. No source is represented as
stating the complete rule verbatim. Protected prose, examples, screenshots,
specimen pages, tables, and branded protocols are not copied.
