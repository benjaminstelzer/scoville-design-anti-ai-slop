- Uses three operations: generate, read-only critique and repair.
- Adds subject-specificity guidance and optional partner coordination to the
  direct index, for 30 draft modules.
- Uses a minimal working record and loads detailed records only for open concerns.
- Preserves historical validation schemas; runtime packaging removes only the
  repository generator comment and retains separate source/runtime hashes.
- Resource estimates remain advisory. Current execution evidence and limits
  are recorded in docs/evaluation/plan-0006-implementation.md.
- Ships a clean 34-file installable directory alongside the authoring source.
- Clarifies read-only critique, standalone operation, external evidence
  references and advisory resource estimates.
- Separates current release checks from historical holdout evidence in
  [release validation](docs/release-validation.md). Genuine host activation
  remains unverified, and no full successor holdout is claimed.
